# Course Monetisation Ladder

Content is the top of the funnel. The ladder underneath it:

| Tier | Offer | Price (SGD) | Purpose |
|---|---|---|---|
| 0 | Free n8n workflow JSON (email capture) | Free | List building |
| 1 | "n8n Starter Pack" — 10 workflows + setup guide | 47 | Buyer conversion |
| 2 | "AI Automation Operator" course — this exact pipeline, taught | 497 | Core revenue |
| 3 | Cohort / live build-along, 6 weeks | 1,997 | Margin + testimonials |
| 4 | Done-for-you automation for SMEs | 5,000+ | Existing business |

**The unfair advantage:** most AI-automation creators teach automation they've never deployed commercially. Teaching the systems you actually run — ERP/CRM software company, property platform — is Tier 2 content nobody can copy, because it comes from operating businesses, not from watching other people's videos.

**CTA discipline** (enforced in Agent B): soft CTA on value posts, hard CTA only 1 in 5 posts. Tier 0 (the free workflow JSON) is the default soft-CTA destination — it feeds the email list that sells Tiers 1–3.

**Flywheel:** post the build of this pipeline as the first content series. The system that makes the content becomes the content.
